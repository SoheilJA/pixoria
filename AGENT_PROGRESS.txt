وضعیت کار: مرحله ۲ — بازطراحیِ سکشن شش دلیل و بخش بعدی صفحه اصلی

- تصمیم: بخش «چرا پیکسوریا» باید ترکیبی از ASCII art، کارت‌های مستقل و کنتراست طلایی/نقاب‌دار باشد تا به‌جای شلوغی، خوانایی و هویت برند را تقویت کند.
- تصمیم: سکشن بعدی (مانیفست/برندهای همکار) باید با نوار متحرک و بلوک متنیِ کنتراست‌دار و بدون وابستگی به کتابخانه‌های جانبی بازطراحی شود.
- تصمیم: از هر ابزار جانبی مثل Hairline و اسکریپت‌های ناموجود صرف‌نظر می‌شود و فقط CSS + HTML برای اجرای الگو استفاده می‌شود.
- اقدام: ساختار HTML برای بخش مانیفست و نوار برندها به‌روزرسانی شد و ASCII art جدید به آن اضافه شد.
- اقدام: سبک‌های CSS برای `why-item`، `client-marquee` و `manifesto` در `static/css/sections.css` بازنویسی شدند تا تجربهٔ موبایل و دسکتاپ هماهنگ بماند.
- اقدام: اسکریپت‌های مردهٔ پایین صفحه حذف شدند تا محتوای اصلی با کم‌ترین وابستگی اجرا شود.
- ذخیرهٔ ادامه: اگر کار ناتمام بماند، با خواندن همین فایل می‌توان از همان نقطه ادامه داد و دوباره از تصمیم‌ها و مرحله‌های انجام‌شده شروع کرد.
